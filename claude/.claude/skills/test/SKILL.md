# テストスキル

## 役割
実装後にテストを実行し、PASS/FAIL を判定する。テストを書くのは `/impl` の責任。ここは**実行と検証のみ**。
実際のテスト実行は **`test-runner` サブエージェントに委譲**する（大量のテストログをメインコンテキストに載せず、軽量モデルで回すため）。あなた（コーディネーター）は引数処理・委譲・結果報告・次工程提示を担う。

## 自走モード（`auto` 引数）
`$ARGUMENTS[1]` が `auto` の場合は自律モード（ブロック抑制）とする。完了カードを出さず、確定した遷移先を 1 行の簡易ログのみ残す。引数なしの単体起動では完了カードを表示する。

## 進め方

### Step 1: 引数チェック
`$ARGUMENTS[0]`（feature）が未指定なら「使い方: /test <feature> [auto]」を表示して終了する。

### Step 2: test-runner へ委譲
`test-runner` サブエージェントを起動し、feature 名を渡す。test-runner が以下を行う：
- プロジェクト CLAUDE.md を最優先にテストコマンドを検出して実行する
- PASS/FAIL を判定する
- 最新結果を `.specs/<feature>/test-report.md` に書き出す（`/fix` の入力源）
- 判定・要点・レポートパスだけを返す（テストログ本体はサブエージェント側に閉じる）

test-runner が「テストコマンドを判断できない」と返した場合は、**推測で実行させ直さず**、単体起動ならユーザーに確認、`auto` 自走時は「判断できない」として報告・停止する。

### Step 3: 完了カード
test-runner の判定（PASS / FAIL）を確定し、末尾「完了カード」のブロックを出力して終了する。「出力フォーマット」の内訳（実行数・失敗テストの一覧）はターミナルに列挙せず、`.specs/<feature>/test-report.md` に記録する。

## 出力フォーマット（test-report.md に書く内訳）
```
## テスト結果: PASS / FAIL

- 実行数: N
- 成功: N
- 失敗: N

### 失敗したテスト（FAILの場合）
- [テスト名]: [エラー内容]
```

## 完了条件
PASS → `/review <feature>` へ。FAIL → `/fix <feature>` へ。

工程を終える際、この工程が本来 catch すべきだった**汎用の**逸脱に気づき、かつ一行の `claim` を書けるなら、`/propose` で提案を1件出す（PJ 固有の事実は該当 PJ の CLAUDE.md/memory へ）。自動では出さず提案に留める。

## 出力規律
実行中の逐次ナレーション（「〜します」「〜しました」）は出さない（ツール実行はターミナルに表示されるため二重になる）。ただし test-runner へ委譲して表示が止まる区間の開始時だけ、次の 1 行を出す（1 区間 1 回）。

⏳ test: test-runner でテストを実行中…

## 完了カード
Step 3 で判定が確定したら、次の完了カードを**コードフェンスで囲まず**プレーンテキストで出力して終了する。カードの前後に作業サマリ・所感・補足を足さない。次スキルは自動起動せずユーザーの実行を待つ。

- ✅ ヘッダの括弧に判定（PASS / FAIL）を入れる。一言サマリは 1 行。主要な結果は `- ` の箇条書きで**最大 3 行**（無ければ行ごと省略）。失敗テストの内訳は test-report.md に寄せ、カードには列挙しない。
- ▶ 行は完了時点で確定した分岐 1 つだけを出す（PASS なら OK 行、FAIL なら NG 行）。

✅ テスト実行完了（PASS）
<実行数と判定を 1 行>
- <主要な結果 最大 3 行>
📄 .specs/<feature>/test-report.md
▶ OK：/review <feature>
▶ NG：/fix <feature>

完了条件を満たせずに終了するときは、同じ構成でヘッダを `⚠ テスト実行中断` に差し替え、一言サマリに中断理由（テストコマンドを判断できない等）、▶ 行に復帰コマンドを書く（レポート未生成なら 📄 行は省略する）。

自律モード（起動引数に `auto` を含む）では完了カードを出さず、確定した遷移先を 1 行の簡易ログだけ残す（例: `次: /review <feature>`）。次スキルの起動は呼び出し元（orchestrator）が行う。
